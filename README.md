# 金融产品推荐系统

面向退休与临近退休人群，围绕用款时间、应急预留、风险承受范围提供金融产品选择服务。首页分为“适合您”“替代方案”“请谨慎选择”，帮助客户发现符合计划的产品，比较替代选择，并识别自己关注过的商品与资金需求之间的冲突。

当前使用报告中的 38 个独立产品：储蓄 10、养老理财 14、保险 8、现金管理 4、其他投资 2；其中 32 个为报告列示的公开产品快照、6 个为明确标识的模拟产品。支持个人注册、登录、账号切换、资金计划、持久收藏和“不感兴趣”管理，管理员可查看商品与推荐服务记录。

## 运行

仅需 Python 3.10 或以上版本，无需额外安装后端依赖。

```bash
python3 backend/server.py
```

打开 <http://127.0.0.1:8000>。新用户选择“注册账号”，注册后填写“我的资金计划”；已有客户首次使用新版本时也需确认资金计划。修改资金计划后，首页自动重新匹配。

初始账号包括 `lin`、`chen`、`wang`、`zhao`、`zhou`、`admin`。首次初始化生成的密码保存在本机 `data/.credentials.json`，该文件及数据库均不提交至仓库。已有账号与密码在升级时保留。会话保存在服务进程内，服务重启后需要重新登录。

## 使用方式

- **我的资金计划**：填写退休状态、养老收入来源（可不提供）、本次资金、应急预留、最早用款日期、风险范围与能否承受本金损失。年龄和退休身份不会自动决定风险范围。
- **适合您**：先检查风险、扣除应急资金后的预算、持有与用款时间、开放状态和购买资格，再排序。条件不满足时允许没有推荐。
- **替代方案**：针对已关注但不匹配的商品，寻找符合同一资金计划的同类产品。在详情中也可以主动查找；无合适替代时直接告知。
- **请谨慎选择**：展示本人实际浏览、收藏或查找替代过的商品与当前计划的冲突，不推送虚构的高风险商品。
- **收藏与偏好**：收藏、取消收藏、不感兴趣、恢复关注均保存到当前账号。不感兴趣的商品不再进入推荐。
- **期限档**：同一银行大额存单的各期限归属一个商品，按客户用款时间匹配可用期限档，详情可展开比较。
- **易读显示**：页面提供标准至 200% 字号选项，支持手机、键盘导航和弹窗焦点管理。
- **管理员**：查看商品目录、规则证据、距离异常与最近推荐记录。普通客户仅能访问本人计划、偏好和推荐；客户界面不展示算法评分。

## 推荐方法

采用二元商品关联规则与加权曼哈顿距离，规则只从有时间记录的真实行为中生成。正向证据使用收藏；负向证据使用关注之后明确表达的“不感兴趣”，统计不同用户，并以发生后续商品接触的人数作为分母，设置最低证据门槛。取消收藏和未继续浏览不作为负面反馈，更不视为亏损。

数据不足时依据个人资金计划与商品特征排序，不生成相似人群结论。存在有效正向规则时按关联 0.60、相似度 0.40 融合；无规则时直接使用个人匹配。距离异常时使用通过同一约束检查的保守排序。详细字段、算法、边界和验收标准见 [项目方案](docs/FINANCIAL_RECOMMENDER_PLAN.md)。

## 数据和图片

商品来源为 `data/actual_products.json`，资料日期为 2026-11-06，参见 [来源与口径](data/actual_products_sources.md)。页面使用 `frontend/assets/retirement/R01.svg` 至 `R38.svg` 的本地产品识别封面，卡片与详情均实际加载图片，封面不绘制收益曲线或伪造品牌宣传。大额存单期限档存入独立子表，在详情折叠展示，不拆分为额外商品。

储蓄展示票面或存款年利率，现金管理展示资料中的七日年化，保险展示保障条款，理财展示业绩比较基准口径。未披露的起购金额、收益和风险等级保持为空，并排除出要求这些信息的个性化推荐。个人养老金产品需核对账户资格与账户内资金，该账户资金不用于普通商品匹配；保险需单独核对承保、缴费与退保条件；模拟产品没有真实购买入口，不进入投资推荐。

已复核部分关键字段：中国银行普通客户大额存单有 7 个期限档；两期国债发行已经结束；平安日增利货币 B 的所查代销门槛为 500 万元，不按低门槛零钱产品推荐。其他资料中不能确认的在售状态保持待确认，不能把“真实产品存在”当作“当前可买”。

不能接受本金损失时，仅考虑符合计划的存款与储蓄国债；仍需核实正式保障、利息和提前退出规则。本服务用于信息筛选，不替代正式风险测评、购买资格核验或专业建议。

## 数据库与导入

采用 SQLite（嵌入式关系数据库）。启动时增量迁移，保留已有账号、客户资料和商品；老行为缺少时间的记录不补造日期，也不参与时序规则。

```bash
python3 scripts/import_actual_products.py /path/to/financial_recommender
```

来源目录应包含 `products.json` 与 `images/`，可附 `DATA_SOURCES.md`。导入验证字段与图片，在事务内更新，先备份数据库到 `data/backups/`。商品身份变化或编号删除时，受影响的行为及偏好归档，避免将原商品的收藏套到另一商品上。相同内容重复导入不覆盖账号、计划和行为。
