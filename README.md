# 金融产品推荐系统

面向退休与临近退休人群，围绕用款时间、应急预留、风险承受范围提供金融产品选择服务。首页推荐区分为“符合计划”和“接近符合”两组，并提供替代方案与请谨慎选择提示，帮助客户发现符合计划的产品，比较替代选择，并识别自己关注过的商品与资金需求之间的冲突。

当前目录共 42 个独立产品：储蓄 14、养老理财 14、保险 8、现金管理 4、其他投资 2。其中 38 个来自报告清单（32 个公开产品快照、6 个明确标识的模拟产品），4 个为工商、建设、中国、邮储银行官网挂牌的个人整存整取定期存款。支持个人注册、登录、账号切换、资金计划、持久收藏和“不感兴趣”管理，管理员可查看商品与推荐服务记录。

## 运行

仅需 Python 3.10 或以上版本，无需额外安装后端依赖。

```bash
python3 backend/server.py
```

打开 <http://127.0.0.1:8000>。新用户选择“注册账号”，注册后填写“我的资金计划”。修改资金计划后，首页自动重新匹配。

初始账号包括 `lin`、`chen`、`wang`、`zhao`、`zhou`、`admin`。新建数据库时，前四个客户账号已有资金计划并标记为种子计划，服务启动时将这些计划的用款日期滚动为当天加各自的 `preferred_term`；`zhou` 可用于体验填写计划，客户保存计划后按用户计划使用日期。`admin` 是管理员。默认每个账号生成独立随机密码，保存在本机 `data/.credentials.json` 的 `{"users": {"账号": "密码"}}` 中，文件权限为 0600，凭据文件和数据库不提交至仓库。环境变量 `FINANCIAL_CUSTOMER_PASSWORD` 和 `FINANCIAL_ADMIN_PASSWORD` 可在生成密码时分别指定客户与管理员密码。缺失、旧格式或损坏的凭据会在启动时重新生成相应种子账号密码；注册账号不受影响。会话保存在服务进程内，8 小时后过期，服务重启后需要重新登录。

## 使用方式

- **我的资金计划**：填写退休状态、养老收入来源（可不提供）、本次资金、应急预留、最早用款日期、风险范围与能否承受本金损失。年龄和退休身份不会自动决定风险范围。
- **符合计划**：先检查风险、扣除应急资金后的预算、锁定期与用款时间、开放状态和购买资格，再按期限、风险和类别偏好排序，最多展示 3 个。
- **接近符合**：展示通过硬约束但仍需确认起购金额、期限或开放状态的商品，并逐条列出待确认事项；预算不足或锁定期超过用款日的商品不进入此组。
- **替代方案**：针对已关注但不匹配的商品，寻找风险不高于原商品的合格候选；同类没有候选时说明类别差异。在详情中也可以主动查找；无合适替代时直接告知。
- **请谨慎选择**：展示本人实际浏览、收藏或查找替代过的商品与当前计划的冲突，不推送虚构的高风险商品。
- **收藏与偏好**：收藏、取消收藏、不感兴趣、恢复关注均保存到当前账号。本人标记“不感兴趣”的商品不进入推荐；恢复关注后可再次参与匹配。收藏用于个人比较，也可触发满足证据门槛的关联规则。
- **期限档**：同一银行大额存单的各期限归属一个商品，按客户用款时间匹配可用期限档，详情可展开比较。
- **易读显示**：页面提供标准至 200% 字号选项，支持手机、键盘导航和弹窗焦点管理。
- **管理员**：查看商品目录、规则证据、无符合商品记录与最近推荐记录。普通客户仅能访问本人计划、偏好和推荐；客户界面不展示算法评分。

## 推荐方法

采用三层适配筛选、二元商品关联规则与加权曼哈顿距离，规则只从有时间记录的真实行为中生成。正向证据使用收藏；负向证据使用关注之后明确表达的“不感兴趣”，统计不同用户，并以发生后续商品接触的人数作为分母。负向规则至少需要 5 位用户和 10 位曝光，按 `0.15 × 置信度` 扣分；正向规则按 `0.2 × 置信度` 加分。取消收藏、未继续浏览和替代行为不作为规则曝光或负面反馈，其中同一客户同一商品每天只记录一次替代行为。

符合候选按期限 0.5、风险 0.3、类别 0.2 排序；已退休或临近退休用户优先较低风险，其他状态更贴近风险上限。锁定期后到账缓冲不足产生软扣分，起购金额只做可行性约束。系统不启用距离兜底；符合组为空时展示接近符合组和资金安排提示，计划过期时提示更新计划。详细字段、算法、边界和验收标准见 [项目方案](docs/FINANCIAL_RECOMMENDER_PLAN.md)。

## 数据和图片

商品来源为 `data/actual_products.json`，资料日期为 2026-11-06，参见 [来源与口径](data/actual_products_sources.md)。页面使用 `frontend/assets/retirement/R01.svg` 至 `R42.svg` 的本地产品识别封面，卡片与详情均实际加载图片，封面不绘制收益曲线或伪造品牌宣传。大额存单和定期存款期限档存入独立子表，在详情折叠展示，不拆分为额外商品。

储蓄展示票面或存款年利率，现金管理展示资料中的七日年化，保险展示保障条款，理财展示业绩比较基准口径。未披露的起购金额、收益和风险等级保持为空，并排除出要求这些信息的个性化推荐。个人养老金产品需核对账户资格与账户内资金，该账户资金不用于普通商品匹配；保险需单独核对承保、缴费与退保条件；模拟产品没有真实购买入口，不进入投资推荐。

已复核部分关键字段：中国银行普通客户大额存单有 7 个期限档；两期国债发行已经结束；平安日增利货币 B 的所查代销门槛为 500 万元，不按低门槛零钱产品推荐。其他资料中不能确认的在售状态保持待确认，不能把“真实产品存在”当作“当前可买”。

不能接受本金损失时，仅考虑符合计划的存款与储蓄国债；仍需核实正式保障、利息和提前退出规则。本服务用于信息筛选，不替代正式风险测评、购买资格核验或专业建议。

## 数据库与导入

采用 SQLite（嵌入式关系数据库）。启动时增量迁移，保留已有账号、客户资料和商品；老行为缺少时间的记录不补造日期，也不参与时序规则。

```bash
python3 scripts/import_actual_products.py /path/to/financial_recommender
```

来源目录应包含 `products.json` 与 `images/`，可附 `DATA_SOURCES.md`。导入验证字段与图片，在事务内更新，先备份数据库到 `data/backups/`。商品身份变化或编号删除时，受影响的行为及偏好归档，避免将原商品的收藏套到另一商品上。相同内容重复导入不覆盖账号、计划和行为。

