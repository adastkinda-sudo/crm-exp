# 金融产品推荐系统

第一版是一个依赖最少的本地 Web 原型，包含金融产品查询、客户画像切换、二项关联规则、加权最近邻、金融约束过滤、异常数据兜底和推荐解释。

## 运行

在项目根目录执行：

```bash
python3 backend/server.py
```

然后打开 <http://127.0.0.1:8000>。

也可以指定端口：

```bash
python3 backend/server.py 8080
```

## 目录

```text
backend/server.py       无第三方依赖的 API 和静态文件服务
data/seed.json          产品、客户和行为演示数据
frontend/index.html     页面结构
frontend/styles.css     视觉样式和响应式布局
frontend/app.js         页面交互和 API 调用
frontend/assets/        本地金融产品图片
docs/                   项目详细实施计划
```

## 演示路径

1. 在“推荐概览”切换 U001、U002 和 U003，观察推荐结果和推荐理由变化。
2. 选择 U999“异常体验用户”，查看超出样例范围和热门产品兜底提示。
3. 在“产品查询”按类别、风险等级和关键词筛选产品，打开产品详情。
4. 在“算法解释”查看当前行为数据计算出的有效关联规则。

演示数据不代表真实金融产品信息，页面内容仅用于课程实验。
