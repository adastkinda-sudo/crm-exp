# 金融产品推荐系统方案

## 一、定位与交付范围

服务退休与临近退休客户，核心任务是帮助客户在保留生活与应急所需的前提下，筛选、比较金融产品。采用报告中的 38 个独立产品，保留现有账户与管理员权限，数据库采用 SQLite。产品不是交易执行系统，不接入真实申购、扣款或收益承诺。

客户界面提供产品信息、个人资金计划、适配提醒、同类比较与偏好管理。算法分数、规则证据及异常信息只面向管理员。商品构成为储蓄 10、养老理财 14、保险 8、现金管理 4、其他投资 2。其中 32 个按报告的公开产品清单整理，6 个保留“模拟”名称与标记。模拟商品不能当作真实在售商品，没有购买入口，也不进入投资推荐。退休身份不直接视为个人养老金购买资格。

## 二、客户路径

1. 注册或登录：仅收集称呼、登录账号和密码。客户可输入另一个账号及密码完成切换。
2. 填写资金计划：退休状态、养老收入来源（含“不便提供”）、本次资金、其中的应急预留、最早用款日期、是否接受本金损失、最高风险等级、关注的商品类别。
3. 浏览首页三组结果：适合您、替代方案、请谨慎选择。
4. 查看商品封面、收益口径、风险、持有安排、起购金额、来源和资料日期。
5. 收藏以备比较，或明确选择不感兴趣；均随个人账号保存，可撤回。
6. 生活安排变化时修改资金计划，重新获得匹配结果。

已有客户资料保留，不自动改年龄、姓名或收入。未填写新计划时，不用原有默认值假装完成适配；引导客户主动确认。退休状态与收入来源用于理解生活安排，不提高或降低客户风险等级，不贴能力不足标签。个人养老金另记录是否已有账户且经销售机构确认资格、以及本次资金中的账户内可用金额。此项客户自述不替代正式核验。

## 三、首页与详情

### 适合您

优先展示最多 3 个通过全部初筛条件的商品。提供简短的匹配说明，不把“符合筛选条件”等同于官方适当性结论。资料不足、计划不全或没有合适商品时展示明确空状态，不为了凑数量降低条件。

### 替代方案

从本人实际浏览、收藏或主动查找过的、不符合计划的商品出发，展示原商品、冲突原因、同类替代商品与差异。详情页也可主动发起查找。没有合适商品时给出无替代结果。不得改变预算、挪用应急资金或提高客户风险等级。

替代只在储蓄、养老理财、保险、现金管理、其他投资的同一大类中寻找，具体资产类型不同必须提示，且不宣称经济等价、同等收益或同等费用。每个方案包含：

- 原商品与初筛结果；
- 可比较商品，或无结果；
- 风险、持有安排与投资类型差异；
- 收益和费用独立计算的提示。

### 请谨慎选择

只显示本人已实际关注过的商品，主要原因包括风险超出、用款冲突、预算不足、起购不明、开放状态待核实、特定购买资格待确认等。有效负向偏好证据可作为“建议再考虑”的补充，不能称为真实亏损或后悔。

### 可读性

采用中文主导航与操作标签，默认 16 像素基础字号、清晰对比度和不小于 44 像素的主要交互目标，提供 125%、150%、200% 字号。手机端结果纵向排列；弹窗支持键盘焦点循环、关闭后返回原位置。38 张封面使用本地 SVG（Scalable Vector Graphics，可缩放矢量图形）路径、固定宽高比例和加载失败替代内容，不生成伪造历史曲线。

## 四、不可放宽的初筛条件

1. 计划已由客户填写确认。
2. 客户不能承担本金损失时，仅考虑标注为普通存款或储蓄国债的商品，仍遵守预算、期限和状态检查，不把保险或理财默认保本。模拟产品始终不推荐。
3. 商品风险等级不高于客户填写的最高范围。此范围仅作初筛，基金目录风险映射不等于销售机构正式评估。
4. 已披露且非估算的起购金额不高于对应账户的可用资金，扣除应急预留后的可安排资金大于零。个人养老金仅用其账户内资金；普通商品使用“本次资金－应急预留－个人养老金账户资金”，两类账户不互相挪用。
5. 最短持有/到期安排已知，并在最早用款日前至少留下 7 天申赎缓冲。该缓冲是平台保守初筛值，不能保证实际到账；0/1 天简化字段不解释为实时赎回或次日到账。明确到期日需同时检查。
6. 来源状态明确开放或在售；“存续”本身不证明可申购，非开放期、暂停、未到募集期或已过募集期应排除。
7. 特定购买资格未确认时不推荐，不能仅凭退休状态推定资格。个人养老金需独立确认账户条件和账户资金；保险需要承保年龄、健康、保费、给付和退保条款核验，当前不直接给出投资适配结论。
8. 大额存单以独立产品计数，`product_variants` 保存期限、起存金额、利率和状态；推荐挑选通过约束的一个期限档，替代可比较所有可用期限档，推荐结果不因期限档重复计数。

评估使用请求当日日期与所存资料；产品状态未连接实时销售系统。完整保留采集日期、原始状态和来源链接，鼓励购买前复核。

## 五、关联规则与匹配算法

### 5.1 行为语义

记录 `view`、`favorite`、`unfavorite`、`avoid`、`restore`、`substitute`，同时保存客户、商品、会话关联和服务器时间。浏览与收藏不能推导出成交；不感兴趣不能推导出亏损或反悔；取消收藏与浏览中断不构成负向证据。恢复关注撤回当前“不感兴趣”状态。

老行为没有可靠日期时保留空值，不伪造先后顺序。归档目录的行为不参与当前目录算法。产品实际浏览、收藏、明确拒绝与主动查找替代可作为实际接触证据；页面加载推荐结果本身不虚构接触行为。

### 5.2 二元正向规则

将每位有可靠时间行为的客户视为一次观察单位，同一客户反复点击不重复增加人数。正向篮子以真实收藏为依据，历史取消收藏不作为负向反馈。

- 支持度：同时收藏 A 与 B 的用户数 / 有效活跃用户数。
- 置信度：同时收藏 A 与 B 的用户数 / 收藏 A 的用户数。
- 兴趣度：置信度 / 收藏 B 的总体比例。
- 门槛：支持度不低于 0.10，且置信度不低于 0.50 或兴趣度大于 1；至少 3 位共同收藏用户、5 位前件用户和 5 位总体有效用户。

个体触发使用当前仍收藏且未设为不感兴趣的前件，历史收藏用于群体证据计数。

### 5.3 二元负向偏好规则

对 A → 不感兴趣 B，要求收藏 A 在先、接触 B 在后，并在其后明确对 B 表达不感兴趣。支持度按不同用户计数，置信度分母仅包括“收藏 A 后实际接触 B”的用户。基线是全部实际接触 B 的用户中明确不感兴趣且未恢复关注的比例。

- 置信度至少 0.50，且相对接触基线的兴趣度大于 1。
- 至少 5 位前件后接触用户、3 位负向反馈用户，支持度至少 0.10。
- 同一客户的重复事件只计一次；晚于拒绝才收藏 A 不成立；缺少时间不成立；恢复关注撤回负向状态。

这仍是选择性样本中的偏好关联，不作因果推断，也不称为亏损预测。证据不足时不产生规则，不显示人群比例。当前数据稀疏时，允许规则为零。

### 5.4 客户与商品距离

采用加权曼哈顿距离，先筛选再计算。客户没有合理的目标收益输入，不从风险偏好虚构收益目标。

| 特征 | 权重 | 距离口径 |
| --- | ---: | --- |
| 风险等级 | 0.40 | 等级差 / 4 |
| 持有期限与用款安排 | 0.30 | 期限差按用款跨度与 365 天的较大值归一化，上限 1 |
| 起购金额负担 | 0.20 | 起购金额与可安排资金的对数比，上限 1 |
| 类别偏好 | 0.10 | 明确偏好不同时为 1，相同时为 0；“全部”时不参与 |

参与特征的权重重新归一化，相似度为 1－距离。收益不进入个人适配评分。此距离度量是排序启发式，不代表成功概率或适配百分比。

有有效正向规则时，最终分数为 0.60 × 关联置信度 + 0.40 × 相似度；没有规则时直接使用个人相似度。负向规则与个人不感兴趣先排除，不通过加分抵消硬约束。

### 5.5 商品替代距离

候选必须通过同一客户全部条件，且未被个人偏好或已触发负向规则排除。权重为风险 0.30、期限 0.25、起购金额 0.20、具体投资类型 0.15、收益 0.10。

风险差除以 4；期限差按 1095 天尺度归一化；金额使用对数尺度；具体投资类型相异为 1。收益仅在同一种历史收益口径、双方均有数值时参与距离比较；存款利率的同期限差异仅用于清楚呈现替代差异，不把业绩比较基准公式转换为收益，也不跨口径比较。缺失字段不补造数值，重分配有效权重。最近候选距离超过 0.60 时返回无替代。

### 5.6 异常与降级

在全部合格候选中的最小个人距离超过 0.60 时，记录持久异常，改为风险较低、持有要求较短、起购金额较低的稳定排序。降级依然遵守所有初筛与偏好约束。没有合格候选时返回空集，不将整个商品目录作为兜底候选，也不伪造热门统计。

## 六、持久化与权限

| 表 | 内容 |
| --- | --- |
| `products` | 报告 38 条商品、图片、收益口径、来源、采集日期、模拟标记、保障与资格类别 |
| `product_variants` | 同一产品的期限档、利率、起存金额、状态与来源 |
| `customers` | 原客户字段及退休状态、收入来源、目标日期、预留金额、损失承受选择、类别偏好、计划完成标志 |
| `users` | 登录标识、角色、客户关联与加盐密码摘要 |
| `behaviors` | 实际行为、服务器时间，旧时间可空 |
| `product_preferences` | 每客户每商品当前收藏与拒绝状态 |
| `association_rules` | 当前有效规则、统计证据与生成时间 |
| `recommendation_logs` | 推荐/替代/谨慎分组结果、商品快照、评分元数据与时间 |
| `abnormal_records` | 去重后的距离异常 |
| `archived_behaviors` | 更换商品身份后的原行为与商品快照 |
| `archived_product_preferences` | 更换商品身份后的原收藏与拒绝状态快照 |

采用增量加列与幂等建表。未知老日期保持未知。迁移前备份，导入采用事务回滚。账号和来源商品不能因界面定位变化而重置。数据库连接在每次操作结束时关闭。

密码使用 PBKDF2（Password-Based Key Derivation Function 2，基于密码的密钥派生函数第二版）与随机盐。服务端会话标识关联用户身份，个人接口从会话获得客户标识；如果显式提交另一客户标识则拒绝。客户不能读取他人账户目录、计划、偏好或推荐。管理员可读取管理和诊断信息。普通客户端结果不包含数值评分。

当前服务仅绑定本机，尚未提供公网部署所需的持久会话、密码找回、完整审计保留/删除政策、管理端写入审批和业务资质接入；不得将此版本描述为已上线销售服务。

## 八、验收标准

- 原有账户凭据与客户原字段逐项保留；活动目录恰为报告 38 个独立产品，期限档不凑数，外键检查通过。原目录备份，旧商品偏好归档。
- 38 张本地封面在卡片与详情中加载，图片路径均能读取与解码；图片不包含伪造收益数值。
- 未完成计划、资金全部预留、用款过近时不产生违规推荐；不能承受损失时仅保留符合条件的储蓄商品。个人养老金资格与资金独立校验。
- 替代与降级不放宽风险、预算、时间、状态和资格约束；无结果是有效状态。
- 时序反转、单用户重复点击、时间缺失与证据不足不能形成负向规则。
- 收藏与拒绝可撤回、重启后保留；切换账号后互不串用。
- 未登录个人接口拒绝访问，跨用户标识拒绝访问，客户不能访问管理员诊断。
- 浏览器实际完成注册、计划保存、商品查看、收藏、替代、切换；检查桌面、手机和 200% 字号。
- 客户页面无汇报、演示、算法评分界面，无虚构收益与人群统计。

## 十、38 条目录的数据边界

报告清单完整导入，报告没有提供的起购金额、正式风险评级、销售批次和源链接不补造。期限按天折算只用于初筛，合同日期为准。中国银行 7 个期限档参考已查公开公告；国债结束发行不改为在售；平安日增利货币 B 按查得的 500 万元渠道门槛处理。其余额度、资格和保险利益缺少证据的项目保留待确认。32 个公开产品清单项不意味着每条产品名称或销售要素都已完成独立核验。逐条来源状态见 `data/actual_products_sources.md`。
